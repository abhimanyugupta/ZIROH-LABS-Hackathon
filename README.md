# Chakravyuh — Urban Flood Intelligence & Safe Routing

**Build Next 2026 — ZIROH LABS / Kompact AI**

Chakravyuh is an AI-assisted urban flood intelligence and decision-support application built around a simple problem: when a city is flooded, the information needed to make good decisions is often scattered across different sources and constantly changing.

The project brings together flood-related information and uses AI to help users understand the situation, identify relevant risks, and support safer decisions and navigation. A key part of the design is that the AI is not treated as an unquestionable answer engine: the system keeps track of evidence, uncertainty, and provenance so users can understand what the system is saying and why.

The Phase-1 qualifying project is an existing project developed before Build Next 2026. This repository is the public competition workspace for the Build Next application and future Phase-2 development.

## Why this project

Flood response is an information problem as much as a physical one. A useful system needs to combine changing information, distinguish evidence from inference, expose uncertainty, and help a person make a decision under pressure.

The long-term direction is to explore how this experience can become more resilient, private, and deployable at the edge — including environments where connectivity, cost, latency, or data sovereignty make a cloud-only AI workflow impractical.

## Phase 2 direction

If selected for the Top 20, this repository may evolve into a fresh Build Next application built around the hackathon's tooling and rules.

A current hypothesis is a **sovereign disaster-response agent** that can operate locally or at the edge and combine:

- local maps and geospatial context
- field reports and incident updates
- multimodal inputs
- evidence/provenance tracking
- persistent local memory
- safe route and resource prioritization
- human-review checkpoints

The final Phase-2 scope will be determined only after the official finalist materials and rules are available.
