# Competition Compliance

This repository separates Phase-1 portfolio work from any future Phase-2 implementation.

## Rules

1. The Phase-1 qualifying project is pre-existing work.
2. Do not represent this repository as proof that a Phase-2 submission already exists.
3. Do not commit finalist-only code before the official Phase-2 challenge period and instructions permit it.
4. Do not publish organizer-confidential material.
5. Before Phase-2 development, re-read the official rules and IP/licensing terms.
6. Do not use external AI/model inference in a future Phase-2 implementation unless the organizer's then-current rules explicitly permit it.
7. Do not make competition submissions or other external actions from repository automation.
